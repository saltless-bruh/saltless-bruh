# saltless-bruh Profile

The public face of the Handle on GitHub: a Profile README staged as one agent-CLI Session, with a Landing Page to follow that shares its visual identity.

## Identity

**Handle**:
The only public identity: the nickname "Lazie" and the account name @saltless-bruh. The real name is never shown.
_Avoid_: real name, full name, display name

**Lazy Operator**:
The core metaphor: the Handle's agents do the work while the operator naps on the box. Lazy means automated, not idle.
_Avoid_: lazy dev, chill coder

**Agentic AI Systems**:
The Handle's AI discipline as one term: autonomous agents plus the local infrastructure they run on, covering applied, adaptive, agentic and local-LLM work.
_Avoid_: Adapt-AI, applied AI, AI engineer

**Mascot**:
Lazie drawn as a cat asleep on top of a server rack in terminal block art; the cat is the Handle made visible, and the rack is the one consumer machine everything runs on.
_Avoid_: logo, avatar, pet, companion, Clawd

## Surfaces

**Profile README**:
The `README.md` of the `saltless-bruh/saltless-bruh` repo, rendered at the top of github.com/saltless-bruh; it ships first.
_Avoid_: profile page, GitHub page

**Landing Page**:
The Handle's own website, built after the Profile README and sharing its visual identity; it becomes the Profile README's primary outbound link.
_Avoid_: portfolio, personal site, Pages site

## Session

**Session**:
The Profile README presented as a single agent-CLI session, from the opening Header to the closing Statusline.
_Avoid_: page layout, dashboard, card stack

**Session Grammar**:
The borrowed layout and glyph conventions of an agent CLI (rule-bordered prompt, tool-call bullets, nested results, spinner, task list, mode badges, effort picker), used without any Anthropic name, logo or mascot.
_Avoid_: Claude Code UI, Claude Code theme

**Command**:
One slash-command invocation and its rendered output; the unit of content inside the Session.
_Avoid_: section, card, block, widget

**Header**:
The opening of the Session: a shell prompt naming the Handle, the host and the path, the Mascot as that prompt's command output, and the role line.
_Avoid_: hero, welcome screen

**Shell Prompt**:
The two rows that open the Header, borrowed from Kali Linux: the Handle, the host and the path in a bracketed first row, and the command the Mascot is the output of in the second. It names the Handle in the one place a shell puts a name, and the Kali shape says what the owner does without a word about it.
_Avoid_: banner, header line, title bar

**Banner**:
The Handle spelled out in terminal block-art lettering. **No longer drawn by the Session**: it and the Mascot were the same visual language and competed, so the Shell Prompt replaced it. The alphabet is kept in `src/banner.ts`, with its tests, for the Landing Page.
_Avoid_: logo, title, wordmark

**Lane**:
A named group of featured repos inside the Session, defined by what the repo serves: Offense (works against targets), Agent Infra (gives agents tools, memory or checks) or Model Infra (keeps local models running on one box).
_Avoid_: category, track, section, local infra, agents lane

**Activity**:
The real, regularly refreshed signals of work: contributions, active days and languages by code size. Stars, followers and self-rated skill levels are excluded.
_Avoid_: stats, metrics, skill bars

**Scan Sweep**:
The Activity visual: the contribution calendar drawn as a target network that a scanner beam sweeps, with busy days lighting up as hits.
_Avoid_: snake, heatmap, contribution graph

**Finding**:
A fault on the rack that wakes the Mascot: the LEDs go red and flash in unison, she hits the chassis twice with a paw, headbutts it, and the machine comes back green. The visible link between the agents' work and Lazie, and the one moment she is awake.
_Avoid_: alert, notification, event, incident

**Statusline**:
The closing panel of the Session: an accent top border, the effort picker set to "lazy", the toggle with its gloss and hints, a mode badge and the not-affiliated-with-Anthropic note.
_Avoid_: footer, effort row

## Look

**Theme Variant**:
One of the two renders of the Session, dark or light, picked by the viewer's GitHub theme; the dark variant is the fallback.
_Avoid_: mode, skin, light/dark version

**Accent**:
The single Everforest aqua-green used for the Handle, the prompt and bullets in both Theme Variants. Status colours appear only inside command output, never as decoration.
_Avoid_: brand colour, highlight, primary
